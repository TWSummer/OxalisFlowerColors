Sources & credits

The study

Chris Brinegar. 2022. The true redwood sorrel: Reinstatement of Oxalis smalliana (Oxalidaceae) as a species separate from Oxalis oregana. Madroño 69(4):304–326. doi:10.3120/0024-9637-69.4.304.

The four color groups follow the study. The proposed vein-contrast protocol and all schematic flower drawings are original project materials. The study's PDF and photographic plate are not redistributed here. The diagrams are conceptual and are not color-calibrated botanical measurements.

Data and software

Records come from the iNaturalist public API. Observation links, user credits, and available observation license codes are preserved in the saved snapshot. Existing community labels are not certified by this project. Field 8625 supplies the default colors; field 43 is an optional alternate. Field 23007 supplies pilot vein-contrast values; independent reliability is not yet established.

Maps use Leaflet 1.9.4 (BSD-2-Clause; license) and OpenStreetMap tiles and data. Map tiles and external photos require a network connection. Typography uses DM Sans and Libre Caslon Display via Google Fonts, with local system-font fallbacks.

Privacy and methodology

Only public, unauthenticated observation data are read. No account credentials are accepted or stored. Private coordinates are neither requested nor reconstructed. Obscured coordinates are hidden by default and explicitly approximate when enabled. The website has no analytics or write access to iNaturalist. Requests to photo, font, tile, and API providers are made by the visitor's browser.

Read the complete protocol, agent instructions, and field configuration. This is an independent project, not an official iNaturalist service.
