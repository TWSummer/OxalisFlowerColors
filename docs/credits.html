The current three color groups and four-trait key follow the project owner’s interpretation of Figure 1, intentionally differing from the paper’s categories. The diagrams are conceptual and are not color-calibrated botanical measurements.

Photographs

The photographic scoring guide uses flower close-ups from photos licensed CC0, CC BY, or CC BY-NC. Each example preserves the available creator attribution, license, source photo, source observation, and crop information. The CC0 photo's API attribution is “no rights reserved”; no photographer name has been inferred. Crops preserve the original color. The guide is intended for this noncommercial website; retain the individual credits and license terms when reusing its images.

The historical pilot images are remotely hosted iNaturalist photographs, displayed without recoloring. Copyright and license terms remain with their creators. The site does not claim ownership of observation photos.

Map popups show photo attribution from the public API and link to each source observation, where current licensing can be checked. Only photos carrying recognized Creative Commons or CC0 license codes are embedded. Dataset and photo licenses can differ. Confirm each current license before other reuse or commercial deployment; remove noncommercial pilot images for a commercial adaptation.

Data and software

Records come from the iNaturalist public API. Observation links, user credits, and available observation license codes are preserved in the saved snapshot. Existing community labels are not certified by this project. The active fields are Redwood Sorrel Petal Color (23008), Petal Vein Contrast (23010), White Center Ring (23011), and Petal Pigment Variation (23012). Earlier fields are retained only in the historical pilot.

Maps use Leaflet 1.9.4 (BSD-2-Clause; license) and OpenStreetMap tiles and data. Map tiles and external photos require a network connection. Typography uses DM Sans and Libre Caslon Display via Google Fonts, with local system-font fallbacks.

Privacy and methodology

Only public, unauthenticated observation data are read. No account credentials are accepted or stored. Private coordinates are neither requested nor reconstructed. Obscured coordinates are hidden by default and explicitly approximate when enabled. The website has no analytics or write access to iNaturalist. Requests to photo, font, tile, and API providers are made by the visitor's browser.

Read the complete protocol, agent instructions, and field configuration. This is an independent project, not an official iNaturalist service.
